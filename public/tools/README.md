# Dossier des icônes pour le bandeau des compétences (Tools Marquee)

Ce dossier permet d'ajouter ou remplacer facilement les logos qui défilent dans le bandeau de la page d'accueil.

## Format recommandé
- **Format** : SVG (`.svg`) ou PNG transparent (`.png`, haute résolution ex: 128x128 ou 256x256).
- **Style** : Logo avec fond transparent ou badge officiel.

## Noms de fichiers reconnus :
Ajoutez ou remplacez simplement les fichiers avec ces noms exacts :

1. `figma.svg` (ou `figma.png`) -> Figma
2. `photoshop.svg` (ou `photoshop.png`) -> Adobe Photoshop
3. `illustrator.svg` (ou `illustrator.png`) -> Adobe Illustrator
4. `indesign.svg` (ou `indesign.png`) -> Adobe InDesign
5. `premiere.svg` (ou `premiere.png`) -> Adobe Premiere Pro
6. `javascript.svg` (ou `javascript.png`) -> JavaScript
7. `typescript.svg` (ou `typescript.png`) -> TypeScript
8. `vue.svg` (ou `vue.png`) -> Vue.js
9. `html5.svg` (ou `html5.png`) -> HTML5
10. `css3.svg` (ou `css3.png`) -> CSS3
11. `canva.svg` (ou `canva.png`) -> Canva
12. `notion.svg` (ou `notion.png`) -> Notion
13. `capcut.svg` (ou `capcut.png`) -> CapCut

Si un fichier n'est pas encore ajouté, un logo vectoriel officiel de secours s'affiche automatiquement.
Dès que vous déposez votre fichier dans ce dossier, le site l'utilisera immédiatement !
